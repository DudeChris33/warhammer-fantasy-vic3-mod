-- not raster position -- so this numbering stays put across a regen: an
unchanged zone keeps its row, a removed zone's row disappears, and a newly
split/added zone appends at the end instead of reshuffling everything above it.
Each row's name is read live off mapgen/config/sea_zones.json's zone_names
(or merges); IMPASSABLE = this zone is flagged impassable (whirlpool, sealed
strait, etc.) in the same file's impassable_seeds.
____________________ = still needs a name. Fill it in here, then copy the
answer into mapgen/config/sea_zones.json's zone_names as
{ "seed": [x, y], "display_name": "..." } (seed = any interior pixel of that
zone read off mapgen/derived/sea_zones.png) and re-run
python mapgen/generate_sea_zones.py to apply it.
