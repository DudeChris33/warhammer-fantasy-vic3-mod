# World-map generator/validator toolchain (mapgen/).
# Not loaded by Victoria 3 — this stack only runs offline to produce and lint
# the committed map data. Install into a local virtualenv:
#
#   python -m venv mapgen/.venv
#   mapgen/.venv/Scripts/pip install -r mapgen/requirements.txt   # Windows
#   mapgen/.venv/bin/pip install -r mapgen/requirements.txt        # POSIX
#
# The toolchain is deterministic for a fixed stack + fixed SEED (see
# mapgen/config/map_config.py).
#
# numpy/Pillow were compatible ranges until 2026-08-20; now exact-pinned like
# scipy/scikit-image below, for the same reason: the EXACT-PINNED policy only
# protects regeneration reproducibility if the whole stack is pinned, and a
# venv rebuild on a fresh machine (this one arrived via a device migration)
# must land on the bytes the goldens were recorded against.

Pillow==12.3.0
numpy==2.2.6

# Added for the source-driven ingestion stage (S2/S3): reprojection
# (control-point warp fields, coordinate resampling), land/sea segmentation
# (morphology, thresholding), coastline/river contour tracing, and the
# vectorized Voronoi/label hot paths that replace the P1 brute-force pure-Python
# primitives at real-canvas scale. All chosen ops are deterministic given fixed
# inputs (no wall-clock/OS entropy, no stochastic segmentation).
#
# opencv-python was deliberately rejected despite covering the same ops: its
# threaded/SIMD kernels carry determinism caveats that are a poor fit for a
# byte-identical multiplayer pipeline. scipy/scikit-image are numpy-backed and
# deterministic.
#
# EXACT-PINNED as of S2 (was a range in S1): the ingestion fixture's golden
# outputs are byte-exact, and scipy's RBF/map_coordinates and scikit-image's
# draw/morphology can differ in their last float bit between library versions —
# a range would let run_fixture.py --check fail on an otherwise-valid clone. The
# committed bitmaps remain the MP source of truth regardless of stack (they are
# static files, identical on every client); this pin protects *regeneration*
# reproducibility. Resolves the S1 security-review INFO item. Bump deliberately,
# then re-run run_fixture.py --update and review the golden diff.
# Stack: numpy 2.2.6, Pillow 12.3.0, Python 3.10.7 (goldens re-verified
# byte-exact on Python 3.10.11 after the 2026-08-20 venv rebuild).
scipy==1.15.3
scikit-image==0.25.2
