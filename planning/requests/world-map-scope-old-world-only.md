# Rescope the map to the Old World only (oceans global, out-of-scope land = one impassable state per continent)

| Field | Value |
|-------|-------|
| Type | request |
| Status | planned |
| Date | 2026-08-17 |
| Priority | high |

## Description

Narrow the current map goal to the **Old World** as covered by the sources in hand,
without changing the canvas. Concretely, the map for this phase is three things:

1. **In-scope land — nine Old World zones as real, subdivided, playable states:**
   Norsca; Kislev; the Empire; Bretonnia; the **Southern Realms** (= Estalia + Tilea
   + the Border Princes, collectively); the Badlands; Nehekhara; the Dark Lands; and
   the parts of the **Karaz Ankor** (Dwarf holds / mountain ranges — Worlds Edge,
   Grey/Black Mountains, etc.) that fall within or between those zones.
2. **Oceans stay global.** Every sea zone across the *entire* canvas remains in scope,
   unchanged. The land limit does not shrink the water.
3. **Out-of-scope land collapses to one impassable state per continent.** Each
   out-of-scope **major landmass** becomes a single state region made of exactly one
   **impassable** province, labelled as an out-of-scope placeholder. Small scattered
   islands fold into the nearest major continent's single province (decision below).

The New World and the east (Cathay and everything beyond the Old World sources) are
**deferred to future work** — the map will eventually expand to fill the canvas, but
not this phase.

## Context

The project was rescoped by the user on 2026-08-17 (see project memory
`project-scope-old-world-only`). Prior planning aimed at a whole-canvas world at
vanilla-order density (~659 land states, per-region minimums including Cathay ≥40 and
a 600–700 total target). That target now applies only to the Old World zones; the
counts that assumed the full canvas (Cathay ≥40, the 600–700 *total*) are deferred
with the geography. The Old-World named-region minimums still stand for this phase
(Empire ≥30, Bretonnia ≥15, Kislev ≥10, Dark Lands ≥30, plus named single-state
requirements — Laurelorn Forest, Middle Mountains, the Moot, Skavenblight, Crater of
Zharr, etc.).

Current map state on disk:
- `map_data/heightmap.png` + `map_data/rivers.png` exist (generated by the pipeline).
- **No `map_data/provinces.png`, no `map_data/state_regions/`, no `map_data/default.map`
  yet** — province subdivision and state-region text (the "S3b" step) is unauthored.
- The state-label layer (`tools/generate_state_labels.py` →
  `tools/derived/state_labels.png`) runs **whole-canvas** and today tries to carve
  *every* landmass (Cathay, Lustria, Naggaroth, …) into cells.
- The Old World boundary sources are registered as four paired-anchor-dot tiles
  (`tww3_old_world_mod_parchment_{empire,bretonnia,kislev_norsca,dark_lands}`); the
  open request `old-world-state-cells-from-dense-boundaries.md` wires them into the
  boundary stack to carve the Old World at density.

Why this rescope matters to the tooling: the whole-canvas generator currently spends
its density budget (and the operator's verdict) on landmasses that are now explicitly
**not** to be subdivided. Under this scope, everything outside the nine Old World
zones must resolve to **one cell → one state → one impassable province per major
continent**, not a carved cell network.

Vanilla confirms the mechanism. Impassable land is expressed inside a normal
`state_regions` entry as an `impassable = { "xHEX" … }` list naming province ids that
belong to the state but are non-traversable (e.g.
`game/map_data/state_regions/00_west_europe.txt` id 7:
`impassable = { "x9000E0" }`). An out-of-scope continent is the degenerate case: a
state whose *single* province id also appears in its `impassable` list. This keeps the
landmass present as coastline for the surrounding sea zones while making it
non-playable — which is also what keeps the global oceans valid, since every sea zone
still borders a real land province.

## Decisions taken with the user (2026-08-17)

- **Continent granularity: major landmasses only.** One placeholder state each for the
  big out-of-scope continents (e.g. Naggaroth, Lustria, Ulthuan, the Southlands south
  of Nehekhara, the eastern lands / Cathay). Small scattered islands (Albion, Sartosa,
  the Isles, offshore rocks) fold into the nearest major continent's single province
  rather than each spawning a state.
- **Coastlines stay real.** Out-of-scope continents keep their true shape from
  `tools/derived/land_sea_mask.png`; only their interior is undivided and impassable.
  Oceans are byte-unchanged. No coastline is simplified or redrawn.
- **Canvas unchanged.** Miller-cylindrical frame as-is (`project-miller-canvas-is-the-frame`).

### Design Decisions
- **The painted zone raster is the single scope + macro authority** — it retires the
  blocked annotated-twin macro path *for this phase* and is robust to the missing crops
  (it even covers Badlands/Nehekhara, which the crops never did). The companion request
  (`old-world-state-cells-from-dense-boundaries`) keeps ownership of **in-scope density**
  (wiring boundary sources inside the zones); its crop-footprint *counting* is superseded
  here. `/build` edits the shared `generate_state_labels.py`; the companion rebases its
  per-zone counts on the zone macros rather than crop footprints.
- **Label layer vs. state.** `validate --labels` check #4 requires every *label* be one
  connected region, so out-of-scope becomes **one label per connected landmass, all
  sharing the one macro** — never a single globe-spanning label. S3b groups that macro
  into the user's single impassable state (a Vic3 state may own disconnected impassable
  provinces). "Islands absorbed, not promoted to a named state, not left as slivers" is
  honoured as: island = its own label under the shared out-of-scope macro → folded into
  the one out-of-scope state at S3b.
- **Oceans are geometry-invariant, not byte-invariant in label *value*.** The collapse
  only relabels land; `cells.sea_zones(~land)` depends solely on the unchanged mask, so
  the sea *partition* (which pixel is which zone) is identical. Only the numeric label
  offset shifts (sea ids start at `n_land+1`, and `n_land` drops) — a relabel, not a
  zone change. Coastlines are byte-identical because the mask is never touched. State
  this precisely in COVERAGE so the renumber is not mistaken for a moved shoreline.
- **Determinism** preserved: `components` + EDT-based cleanup, no RNG, sorted iteration
  (`map_config.SEED` unused by the collapse).

### Edge Cases
- **Zone map frame/dims mismatch.** If the export is not exactly `8192×3616` (i.e. the
  user painted on a non-canvas frame), fail fast with a clear message — it would need
  registration, which this design deliberately avoids. Confirm dims at build.
- **Zone/out-of-scope seam.** A cell straddling a zone↔out-of-scope boundary is assigned
  by **majority** `zone_of` area; run the in-scope and out-of-scope `MIN_CELL_AREA`
  cleanups **within their own partition** so a sub-floor coastal fragment never merges
  across the scope boundary and flips macro.
- **Single macro over many landmasses is expected** and is *not* a check-#4 violation —
  each label is still connected; only the macro groups many labels.
- **Out-of-scope tiny rubble** adjacent to a bigger out-of-scope cell merges (check #7);
  a genuinely isolated tiny island (no same-kind neighbour) is legitimately kept, exactly
  the carve-out `validate_labels` check #7 already documents.
- **In-scope zone painted over water.** Clipped by `land` as usual (the mask stays the
  coastline authority); a zone contributes nothing where the mask says sea.
