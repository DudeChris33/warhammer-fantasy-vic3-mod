# common/flag_definitions is a replace_paths folder. This mod's DEFAULT list
# (00_flag_definitions.txt) ships one unconditionally-applicable block at
# priority = 0 — so "no flag definition is applicable for a country" (vanilla's
# own tag-as-COA_KEY fallback condition) never fires for any tag. Without a
# higher-priority tag-named list here, every bespoke COA in
# common/coat_of_arms/coat_of_arms/05_southern_realms.txt (#3627, epic #3621)
# would parse but sit unused behind default_flag. Each list below is a single
# unconditional block at priority = 100 — above #3552's priority = 0 DEFAULT,
# below vanilla's own conditional range of 100-2000 for future per-tag variants.
# `always = yes` confirmed valid at docs/triggers.log. Shape matches #3622's
# common/flag_definitions/02_empire.txt exactly. 27 tags, same order as
# common/country_definitions/05_southern_realms.txt.
