# (00_flag_definitions.txt) ships one unconditionally-applicable block at
# priority = 0 — so "no flag definition is applicable for a country" (vanilla's
# own tag-as-COA_KEY fallback condition, see that file's vanilla header comment
# at .../game/common/flag_definitions/00_flag_definitions.txt:1-14) never fires
# for any tag. Without a higher-priority tag-named list here, every bespoke COA
# in common/coat_of_arms/coat_of_arms/04_karaz_ankor.txt (board #3624) would

# unconditional block at priority = 100 — above #3552's priority = 0 DEFAULT,
# below vanilla's own conditional range of 100-2000 for future per-tag variants.
