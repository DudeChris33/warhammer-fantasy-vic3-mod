# Partial port of vanilla common/power_bloc_coa_pieces/00_power_bloc_coa_pieces.txt (#6574).
# common/power_bloc_coa_pieces is blanked by replace_paths. This is the catalogue the
# power bloc coat-of-arms customization screen offers; the order here is the order in the
# UI. Vanilla order and vanilla `colors` values are kept for every entry that survives.
#
# Format (vanilla):
# filename = {
#     # How many colors options to show for this piece. Optional, will assume 0 if missing, where 0 means
#     # this is a textured asset that doesn't require custom colors.
#     colors = 3
#
#     # Which piece is this? Available: shield_pattern, shield_frame, center, top, side.
#     piece = center
# }
#
# Curation (heraldry.md, "Power bloc coats of arms"): the centre set is the SAME curated
# set as power_bloc_center in common/coat_of_arms/template_lists/colored_emblem_lists.txt
# (see the exclusion record there), plus vanilla's blank "none" centre pb_center_11. Dropped
# wholesale: vanilla's real-world national charges (pb_crescent_star_turkey,
# pb_eagle_doubleheaded, pb_bear, pb_iron_cross, pb_lion_passant_guardant) and its
# Islamicate, Christian, Sikh, Jewish, Dharmic, Communist/Socialist, Fascist/Ultranationalist
# and Pagan groups. Tops: pb_top_01 (crescent) and pb_top_03 (elephant) dropped; pb_top_06
# is vanilla's blank "none" top. Sides pb_side_00..06 (06 is the blank "none") and frames
# pb_frame_00..04 are kept as vanilla.
# All textures are vanilla's own gfx/coat_of_arms/{colored,textured}_emblems/pb_*.dds,
# reused as-is (no copies in this mod).
