# is an in-game error. Both variants carry magnitude 1 — that is the vanilla shape (confirmed
# against the vanilla common/static_modifiers/ reference) and is mirrored here deliberately.
# This file is APPENDED to by each culture-authoring item in epic #3404 (#3406, #3407, #3408,
# #3409) as new cultures are added.
