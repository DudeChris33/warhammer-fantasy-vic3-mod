# common/coat_of_arms/coat_of_arms is a replace_paths folder, so vanilla's copy of
# this file does NOT load. Bespoke content per epic #3621 child #3628 — the 11
# Badlands/Greenskin country tags (common/country_definitions/06_badlands.txt,
# same order). Composed from vanilla gfx/coat_of_arms/ art (patterns +
# colored_emblems, neither blanked by replace_paths), this mod's named_colors
# palette (common/named_colors/00_coa_colors.txt + 01_wh_coa_colors.txt — five new
# entries appended for this file: orc_green, goblin_moss, bone, gore_red,
# dirty_iron), and one vendored Realms of Exether emblem (ce_gallic_boar.dds,
# ICL's secondary charge). Design language: a deliberate house style distinct from
# every "civilised" tag file shipped so far — one oversized/off-centre charge (two
# max), a closed two-colour-max palette, no quartering/crown/laurel framing, and a
# ban on real-world-extremist and real-world-ethnographic-sacred devices (see
# .claude/rules/scripting.md's greenskin house style section for the full
# 10-rule list this file was built against). Each block below records its canon
# confidence + substitution reasoning per #3621's "record every substitution"
# acceptance criterion, matching 02_empire.txt/03_brettonia.txt/05_southern_
# realms.txt's discipline. Requires common/flag_definitions/06_badlands.txt (this
# mod's DEFAULT flag_definitions block is unconditional at priority = 0 and would
# otherwise mask every one of these) to actually render in-game.
