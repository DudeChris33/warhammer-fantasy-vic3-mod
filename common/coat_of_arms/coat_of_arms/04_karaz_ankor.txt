# Dwarf hold tags (KAZ the formable, plus 17 karaks). Composed from vanilla
# gfx/coat_of_arms/ art (patterns + colored_emblems, neither blanked by
# replace_paths) plus two emblems reused from the permissioned Realms of Exether
# sibling mod (gfx/coat_of_arms/colored_emblems/ce_roe_axes.dds and

# palette (common/named_colors/00_coa_colors.txt). Every substitution/asset
# source is disclosed in the comment above its block, following the
# 02_empire.txt precedent. Requires common/flag_definitions/04_karaz_ankor.txt
# (this mod's DEFAULT flag_definitions block is unconditional at priority = 0
# and would otherwise mask every one of these) to actually render in-game.
# TWW3/canon-alignment pass (2026-09-22): field colours for KAZ/KAK, ZHU, KAD,
# BVR, AZL, KNO, KHI and KEP corrected against the published hold-colour record
# (Warhammer Armies: Dwarfs / White Dwarf studio schemes, catalogued at
# cragfistsbrewery.weebly.com/dwarf-hold-colours.html — the only holds GW ever
# gave an official uniform/heraldic colour to are exactly these plus Karak
# Izor, Eight Peaks' pre-conquest name) — the earlier field colours for those
# eight tags were invented guesses. Every other hold in this file (the seven
# "ruined holds" and KRD, KAG) has no published colour on record, so their
# existing invented fields are unchanged. Charges are unchanged except where
# noted per-block.
