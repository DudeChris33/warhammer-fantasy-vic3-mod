# common/coat_of_arms/coat_of_arms is a replace_paths folder, so vanilla's copy of
# this file does NOT load. Bespoke content per epic #3621 child #3627 — the 27
# Southern Realms country tags (common/country_definitions/05_southern_realms.txt,
# same order; the roster grew from the originally-filed 15 to 27 after that file's
# 2026-09-06 expansion — DON plus the 11 named Border Princes belt realms — see
# this item's own premise-check note). Composed from vanilla gfx/coat_of_arms/ art
# (patterns + colored_emblems, neither blanked by replace_paths), this mod's
# named_colors palette (common/named_colors/00_coa_colors.txt +
# 01_wh_coa_colors.txt), and six Realms of Exether emblems (reuse grant
# 2026-09-07; provenance noted per-block below) plus three more RoE emblems
# already vendored into this repo by earlier siblings and reused here as-is
# (ce_roe_mountain.dds from #3624, ce_bear_smo.dds and ce_cup.dds from #3625/
# #3623 respectively — no new vendoring for those three). Loremaster-consulted
# during scoping. Design language: warm ochre/terracotta/sea-green Tilean civic
# heraldry, crimson/gold Iberian-Reconquista Estalian heraldry (castle, Santiago
# cross, pilgrim scallop kept deliberately per the epic's "loreful fit comes
# first" directive — a strong, canon/name-derived Mediterranean-Iberian charge is
# not swapped out for reading real-world-adjacent), and an earthy dun/brick/moss
# Border Princes belt following each realm's own filed heraldic hint. Each block
# records its provenance bucket per #3621's "record every substitution"
# acceptance criterion, matching 02_empire.txt/03_brettonia.txt/01_kislev.txt's
# discipline. Requires common/flag_definitions/05_southern_realms.txt (this mod's
# DEFAULT flag_definitions block is unconditional at priority = 0 and would
# otherwise mask every one of these) to actually render in-game.
