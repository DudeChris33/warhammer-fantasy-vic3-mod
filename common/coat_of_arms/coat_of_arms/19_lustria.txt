# a green-teal family field per tag (the palette tincture nearest its legend colour; lustrian_jade and lustrian_turquoise
# in named_colors/01_wh_coa_colors.txt), one charge per tag in golden or pearl, a thin golden frame (ce_border_thin) on

# Every texture and colour-slot count is cited per block against a real usage (game/common/coat_of_arms/coat_of_arms/
# unless marked RoE or mod); where vanilla fills one slot only, slot 2 is set to slot 1's tone (the AVE convention).
# Each block names its canon-confidence bucket.
# Requires common/flag_definitions/19_lustria.txt to render in-game (this mod's DEFAULT flag_definitions block is
# unconditional at priority = 0). Commit and deploy with or after #10181's definitions, so no flag list names an
# undefined tag.
