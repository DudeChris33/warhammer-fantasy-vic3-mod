# Country tags — Ulthuan and the High Elf colonies. Board item #8444 (epic #3414); roster frozen in
# planning/tag_registry.md, region "17 ULTHUAN".
#
# Entry schema (see .claude/rules/peoples.md):
#   color        — { R G B } with 0-255 integers.
#   country_type — recognized | unrecognized | colonial | company | decentralized
#   tier         — city_state | principality | grand_principality | kingdom | hegemony | empire
#   cultures     — culture ids from common/cultures/high_elf.txt (#8463; cross-file reference)
#   capital      — STATE_* key from map_data/state_regions/ (field order as vanilla: after cultures)
#
# COLOUR NOTE: every start tag below copies its colour EXACTLY from
# mapgen/config/state_ownership_legend.json — the painted ownership map is keyed on that RGB, so the
# legend wins over the usual reuse-the-culture-colour convention (#6373). LOT's legend colour is also
# the high_elf culture colour. ULT, the formable, is not painted and takes a darker shade of LOT's.
#
# FILING NOTE: the six colonies (CDU FDW TEL TOS GCL TEH) follow the registry's region column
# (17_ulthuan), not the geography of their states: STATE_ISLES_OF_DUSK sits in
# map_data/state_regions/19_lustria.txt, the Fortress of Dawn, Tor Elasor and Tower of the Stars
# states in 09_southlands.txt, and the Gates of Calith and Lost Isles of Elithis states in
# 15_khuresh.txt. The High Elves are one people with one region file (the exception KRD and the ogre
# tribes take). Their names come from sources/originals/High_Elf_Outposts.JPG (Chris's source).
#
# The ten kingdoms are recognized kingdoms, protectorates of LOT at start; the six colonies are
# colonial principalities, LOT's colonies at start (common/history/diplomacy/00_subject_relationships.txt).
# The colonies take gov_principality: law_colonial_administration is not emitted (see
# mapgen/config/country_history/README.md, Mechanics gaps).
#
# capital convention (#3658; full rule in .claude/rules/peoples.md). No Ulthuan or colony state has
# a named hub, so C1 is read as the state judged to hold the canon seat from the state name and canon
# geography (Chris-accepted reading, #8444), commented "seat inferred: no named hub":
#   C1 a tag's capital is the state holding its canon seat, whoever owns that state at start;
#   C2 a land-owning tag with no seat placeable with confidence takes its largest owned state
#      (province count in mapgen/derived/state_ownership.json, ties on higher arable_land),
#      commented "non-canon";
#   C3 a tag that owns nothing at start and has no canon seat omits capital.
# Never use a STATE_LAND_<n> key. No offline gate checks these keys: after any state rename or
# regeneration, grep "capital =" in common/country_definitions/ against map_data/state_regions/.
#
# Country display names/adjectives live in localization/english/countries_17_ulthuan_l_english.yml
# and, for tags whose key collides with vanilla (ULT CAL NGY TIR), in
# localization/replace/english/countries_17_ulthuan_l_english.yml.
# The ULT formation rule lives in common/country_formation/17_ulthuan_formables.txt.
