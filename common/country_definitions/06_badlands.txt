# Country tags — the Badlands. Board item #3419 (epic #3414); roster frozen in
# planning/tag_registry.md, region "06 BADLANDS".
#
# Entry schema (see .claude/rules/scripting.md):
#   color        — { R G B } with 0-255 integers. Orc tags sit in the earthy mid-green band seeded
#                  from the orc culture color in common/cultures/greenskin.txt (74 106 46);
#                  goblin tags sit in a DELIBERATELY darker moss/black-green band rather than the
#                  goblin culture's own pale green (148 170 84), so that on a map crowded with
#                  twelve greenskin tags the orc tribes and the goblin tribes read apart at a
#                  glance. That is the one place this file departs from the "reuse the culture
#                  color" convention, and it departs on purpose.
#   country_type — recognized | unrecognized | colonial | company | decentralized
#   tier         — city_state | principality | grand_principality | kingdom | hegemony | empire
#   cultures     — culture ids from common/cultures/greenskin.txt
#
# ALL TWELVE are unrecognized/principality (Chris, 2026-09-04 — supersedes the original decentralized
# choice). Greenskin tribes and WAAAGH!s hold no court and sign no treaty, but unrecognized (not
# accepted as a legitimate power by the civilised order) reads better than decentralized (uncoordinated
# territory) for a tribe that IS coordinated by its warlord. The principality tier keeps them small
# without implying a crown.
#
# NO FORMABLE in this region — Chris dropped the Grand WAAAGH! (WAG), so there is deliberately no
# common/country_formation/06_badlands_formables.txt and no WAG tag reserved.
#
# capital: DELIBERATELY OMITTED on every entry. No land map_data/state_regions/ exist yet (only the
# sea zones emitted by tools/generate_sea_regions.py), so any capital = STATE_* would dangle. The
# intended capital is recorded as a comment per tag and becomes a real field once land states exist.
# Country display names/adjectives live in localization/english/countries_badlands_l_english.yml.
