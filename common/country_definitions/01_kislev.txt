# Entry schema (see .claude/rules/scripting.md):
#   color        — { R G B } with 0-255 integers.
#   country_type — recognized | unrecognized | colonial | company | decentralized
#   tier         — city_state | principality | grand_principality | kingdom | hegemony | empire
#   cultures     — culture ids from common/cultures/kislevite_humans.txt
#   capital      — STATE_* key from map_data/state_regions/ (field order as vanilla: after cultures)
#
# capital convention (#3658; full rule in .claude/rules/peoples.md):
#   C1 a tag's capital is the state holding its canon seat's city hub, whoever owns that state at
#      start — a claimant or formable keeps its canon seat;
#   C2 a land-owning tag with no canon seat takes its largest owned state (province count in
#      mapgen/derived/state_ownership.json), commented "non-canon";
#   C3 a tag that owns nothing at start and has no canon seat omits capital, with
#      "# capital: none - <reason>".
# Never use a STATE_LAND_<n> key. No offline gate checks these keys: after any state rename or
# regeneration, grep "capital =" in common/country_definitions/ against map_data/state_regions/.
# Country display names/adjectives live in localization/english/countries_kislev_l_english.yml.
# The KIS formation rule lives in common/country_formation/01_kislev_formables.txt.
