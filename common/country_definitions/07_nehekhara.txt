# Country tags — Nehekhara. Board item #3419 (epic #3414); roster frozen in
# planning/tag_registry.md, region "07 NEHEKHARA".
#
# Entry schema (see .claude/rules/scripting.md):
#   color        — { R G B } with 0-255 integers. Seeded from the nehekharan culture color in
#                  common/cultures/nehekharan_araby.txt (204 178 96): a sand/bronze/turquoise family,
#                  bronze for the smith-cities and turquoise for the two river-and-sea cities.
#                  LAH takes the lahmian_vampire culture color unchanged — a dark carmine-violet
#                  that belongs to no part of the Tomb Kings' palette, which is the point.
#   country_type — recognized | unrecognized | colonial | company | decentralized
#   tier         — city_state | principality | grand_principality | kingdom | hegemony | empire
#   cultures     — culture ids from common/cultures/nehekharan_araby.txt
#   capital      — STATE_* key from map_data/state_regions/ (field order as vanilla: after cultures)
#
# capital convention (#3658; full rule in .claude/rules/peoples.md):
#   C1 a tag's capital is the state holding its canon seat's hub (any hub type), whoever owns that
#      state at start — a claimant or formable keeps its canon seat (vanilla does the same: POL, ITA,
#      and a dozen tags share STATE_AMHARA);
#   C2 a land-owning tag with no canon seat takes its largest owned state (province count in
#      mapgen/derived/state_ownership.json), commented "non-canon";
#   C3 a tag that owns nothing at start and has no canon seat omits capital, with
#      "# capital: none - <reason>".
# Never use a STATE_LAND_<n> key. No offline gate checks these keys: after any state rename or
# regeneration, grep "capital =" in common/country_definitions/ against map_data/state_regions/.
#
# Every tag here is unrecognized: the risen dead of the Great Land keep no place in the recognized
# order of the living Old World, whatever their own antiquity. The tomb-cities are kingdoms (each
# has its Tomb King), NEH is the empire that reunites them, and LAH is a lone city_state.
# Country display names/adjectives live in localization/english/countries_nehekhara_l_english.yml.
# The NEH formation rule lives in common/country_formation/07_nehekhara_formables.txt.
