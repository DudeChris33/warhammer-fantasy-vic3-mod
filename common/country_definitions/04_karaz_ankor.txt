# Country tags — the Karaz Ankor, the Dwarf Empire. Board item #3418 (epic #3414); roster frozen in
# planning/tag_registry.md, region "04 KARAZ ANKOR".
#
# Entry schema (see .claude/rules/scripting.md):
#   color        — { R G B } with 0-255 integers. Derived from the polity's own culture color in
#                  common/cultures/dwarven.txt so tag and culture read as one thing:
#                  dawi reddish (156 44 40), dawi_grey grey-blue (128 128 132), dawi_norse cold
#                  blue (96 140 168), dawi_ancestral earthy brown (110 74 48). The seven ruined
#                  holds take a desaturated variant of their own culture's color.
#   country_type — recognized | unrecognized | colonial | company | decentralized
#   tier         — city_state | principality | grand_principality | kingdom | hegemony | empire
#   cultures     — culture ids from common/cultures/dwarven.txt
#   capital      — STATE_* key from map_data/state_regions/ (field order as vanilla: after cultures)
#
# capital convention (#3658; full rule in .claude/rules/peoples.md):
#   C1 a tag's capital is the state holding its canon seat's hub (any hub type), whoever owns that
#      state at start — a claimant, formable or ruined hold keeps its canon seat;
#   C2 a land-owning tag with no canon seat takes its largest owned state (province count in
#      mapgen/derived/state_ownership.json), commented "non-canon";
#   C3 a tag that owns nothing at start and has no canon seat omits capital, with
#      "# capital: none - <reason>".
# Never use a STATE_LAND_<n> key. No offline gate checks these keys: after any state rename or
# regeneration, grep "capital =" in common/country_definitions/ against map_data/state_regions/.
# Country display names/adjectives live in localization/english/countries_karaz_ankor_l_english.yml.
# The KAZ formation rule lives in common/country_formation/04_karaz_ankor_formables.txt.
#
# The seven ruined holds (KUN, KVN, EKR, GUN, DRZ, VLG, SLV) are kept as dwarf tags even though
# each is occupied by greenskins or Skaven at game start — they are releasable "reclaim" realms.
# Their occupiers are separate tags (the greenskin ones in 06_badlands). Tiers set 2026-09-04
# (Chris): DRZ is grand_principality, the other six ruined holds are principality — the earlier
# city_state tier (rump claimant, not a functioning hold) was dropped.
