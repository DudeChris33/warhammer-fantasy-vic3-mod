# Old World cultures — Bretonnian humans. Schema mirrors common/cultures/norscan_humans.txt, the
# verified reference entry for this mod. Each culture carries:
#   color      — rgb{ R G B } with 0-255 integers. Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
#   noble_last_names / male_regal_first_names / female_regal_first_names are OPTIONAL (confirmed
#                against vanilla, where many cultures omit them) and are used here only for the
#                cultures that have a real aristocracy in Warhammer lore.
#   graphics/ethnicities — vanilla portrait ids, confirmed present in the vanilla
#                common/culture_graphics/ and common/ethnicities/ databases. Custom art is out of
#                scope for epic #3404.
# Multi-word names use vanilla's underscore convention (de_Lyonesse), displayed via the loc key.
# Every name string used below also needs a matching localization key unless vanilla already ships
# one — see localization/english/cultures_names_l_english.yml. Every culture additionally needs its
# six static modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Board item #3407 (epic #3404).
