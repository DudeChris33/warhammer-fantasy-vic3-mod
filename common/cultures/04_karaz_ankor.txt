# Old World cultures — the Karaz Ankor, the Dwarf Empire. Schema mirrors
# common/cultures/00_norsca.txt and 02_empire.txt, the verified reference entries for this mod.
# Each culture carries:
#   color      — rgb{ R G B } with 0-255 integers. Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
#
# GOVERNING PRINCIPLE — "one people, four cultures". All four Dawi cultures share
# heritage_dawi and sphere_khazalid, so they accept and assimilate one another freely with no
# scripting at all: the shared heritage and shared language do the work. The split between them
# is expressed ENTIRELY through surname stock and light first-name shifts, never through the
# language field. Dwarfs do not name their children in the tongue of the umgi, so no culture
# here carries a loaned FIRST name; only dawi_grey takes a light minority of Reikspiel-loan
# SURNAMES, from centuries of Empire and Bretonnian trade.
#
# dawi_badlands is filed here, with its kin, rather than in 06_badlands.txt: culture files in
# this mod group by RACE, not by the geography of the states a culture happens to occupy.
#
# graphics/ethnicities — vanilla ships no dwarf portrait set. `european` plus the ginger- and
#                brown-weighted caucasian morphs is a deliberate STAND-IN, chosen as the closest
#                available match to canon dwarf colouring, pending custom dwarf art. Custom art
#                is out of scope for epic #3404.
# Every name string used below also needs a matching localization key unless vanilla already
# ships one — see localization/english/cultures_names_l_english.yml. Every culture additionally
# needs its six static modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Culture display names live in localization/english/cultures_karaz_ankor_l_english.yml.
# Board item #3408 (epic #3404).
