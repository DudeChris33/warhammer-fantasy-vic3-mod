# Old World cultures — the Dawi, the Dwarf Empire's people. Schema mirrors
# common/cultures/norscan_humans.txt and common/cultures/imperial_humans.txt, the verified
# reference entries for this mod. Each culture carries:
#   color      — rgb{ R G B } with 0-255 integers. Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
#
# GOVERNING PRINCIPLE — "one people, four cultures". All four Dawi cultures share
# heritage_dawi and sphere_khazalid, so they accept and assimilate one another freely with no
# scripting at all: the shared heritage and shared language do the work. The split between them
# is expressed ENTIRELY through surname stock and light first-name shifts, never through the
# language field. Dwarfs do not name their children in the tongue of the umgi, so no culture
# here carries a loaned FIRST name; only dawi_grey takes a light minority of Reikspiel-loan
# SURNAMES, from centuries of Empire and Bretonnian trade.
#
# dawi_ancestral (formerly dawi_badlands, renamed on manual audit 2026-09-03) is filed here, with
# its kin, rather than by the geography of the Badlands: culture files in this mod group by
# RACE/CULTURE-GROUP, not by the geography of the states a culture happens to occupy — the
# convention this file originated, now applied mod-wide (dark_lands' Chaos Dwarfs are likewise
# filed by kin in common/cultures/chaos_dwarf.txt, and their Hobgoblin hirelings by kin in
# common/cultures/greenskin.txt).
#
# AGE, NOT JUST GEOGRAPHY (per Chris, 2026-09-03; confirmed via Total War/Fandom lore on the
# Dwarfs' founding migration): the Dawi did not spread outward evenly from one ancestral seat.
# They founded their FIRST holds in the deep south (Karak Zorn and its kin, near modern Karak
# Azul/Eight Peaks/Ekrund/Drazh) and only afterward pushed north into the World's Edge heartland
# (Karaz-a-Karak) where gold and gromril were richest — the heartland is where the High King's
# throne and the greatest numbers ended up, but it is NOT the oldest Dawi stock. Dwarfs went
# further north still, generations later, to found the Norse holds. So the real seniority order,
# oldest to youngest, is: dawi_ancestral (the First Holds) → dawi (the World's Edge expansion,
# now dominant in numbers and political weight) → dawi_norse (the last, most isolated push). This
# reframes dawi_ancestral from "the holds that happen to sit in the Badlands and keep losing
# ground" to "the eldest kin, who hold the oldest ancestor-lore and privately regard even
# Karaz-a-Karak as comparatively young" — the sieges they've suffered are real, but not their
# whole identity. dawi_grey (the Grey Mountains/Vaults trading holds) sits outside this
# seniority axis entirely — theirs is a lateral distinction (constant contact with umgi traders),
# not a generational one, so it is left as-is.
#
# graphics/ethnicities — vanilla ships no dwarf portrait set. `european` plus the ginger- and
#                brown-weighted caucasian morphs is a deliberate STAND-IN, chosen as the closest
#                available match to canon dwarf colouring, pending custom dwarf art. Custom art
#                is out of scope for epic #3404.
# Every name string used below also needs a matching localization key unless vanilla already
# ships one — see localization/english/cultures_names_l_english.yml. Every culture additionally
# needs its six static modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Culture display names live in localization/english/cultures_dwarven_l_english.yml.
# Board item #3408 (epic #3404).
