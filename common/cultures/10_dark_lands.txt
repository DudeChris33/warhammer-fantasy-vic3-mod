# Old World cultures — the Dark Lands. Schema mirrors common/cultures/00_norsca.txt and
# 02_empire.txt, the verified reference entries for this mod. Each culture carries:
#   color      — rgb{ R G B } with 0-255 integers. Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
# graphics/ethnicities — vanilla ships no Chaos Dwarf or greenskin portrait set. The values used
#                below are deliberate STAND-INS pending custom art, which is out of scope for
#                epic #3404.
# Every name string used below also needs a matching localization key unless vanilla already
# ships one — see localization/english/cultures_names_l_english.yml. Every culture additionally
# needs its six static modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Culture display names live in localization/english/cultures_dark_lands_l_english.yml.
# Board item #3408 (epic #3404).

################ Dawi Zharr — the Chaos Dwarfs of Zharr Naggrund ################
# A DIFFERENT racial heritage from the Dawi (heritage_dawi_zharr, its own trait group — the
# Chaos Dwarfs are hated on sight by every other race, and by their own kin above all), but
# their tongue is still Khazalid, debased: sphere_khazalid_zharr shares sphere_group_khazalid
# with true Khazalid, so a true dwarf understands a Chaos Dwarf perfectly well and hates what he
# hears. The names keep the Khazalid consonant skeleton but lean into zh/kh/gh digraphs, and
# every ancestor-honouring element has been replaced with fire, iron, bull, ash and chain.
# noble_last_names carry the priest-caste and slaver titles plus the ziggurat-cities themselves;
# the regal lists are the Sorcerer-Prophets.

################ Hobgoblin — the Hobgobla Khanate; the Chaos Dwarfs' hired treachery ################

# goblin, and they speak sphere_greenskin. Names are short, guttural and two-syllable, with a
