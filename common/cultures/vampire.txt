# Old World cultures — the vampire bloodlines. Schema mirrors common/cultures/norscan_humans.txt,
# the verified reference entry for this mod. Each culture carries:
#   color      — rgb{ R G B } with 0-255 integers. Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
# Every culture here shares heritage_vampire (heritage_group_undead) and cult_of_nagash, but keeps
# the LANGUAGE of the mortal population it rose from — sylvanian_vampire speaks sphere_reikspiel,
# lahmian_vampire speaks sphere_nehekharan — because vampires are risen from among their own
# subjects, not a people apart with a tongue of their own. This is what keeps them filed as
# separate cultures rather than one shared "vampire" culture id. Culture files in this mod group
# by RACE/CULTURE-GROUP, not by the geography of the states a culture happens to occupy: both
# bloodlines below were previously filed alongside the mortal cultures they rose from
# (common/cultures/imperial_humans.txt, common/cultures/nehekharan_araby.txt) and are gathered here
# instead — see common/cultures/dwarven.txt for the convention's origin case.
# Every name string used below also needs a matching localization key unless vanilla already ships
# one — see localization/english/cultures_names_l_english.yml. Every culture additionally needs its
# six static modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Culture display names live in localization/english/cultures_vampire_l_english.yml.
# Board items #3406, #3409, #3415, #3419 (epic #3404).

################ Lahmian Vampire — Neferata's bloodline; the cradle of vampires ################
# The FIRST vampires: Neferata of Lahmia drank Nagash's Elixir and made her court immortal. They are
# Nehekharan-born (sphere_nehekharan — they speak the tongue of the Great Land) but a DIFFERENT
# racial heritage from the nehekharan Tomb Kings they seceded from: heritage_vampire, in
# heritage_group_undead, the Nagashite line — and cult_of_nagash, not the mortuary_cult. That split
# is deliberate and is this culture's whole thesis: Settra's dead and Neferata's dead are enemies.
# The Nagashite names the nehekharan culture (common/cultures/nehekharan_araby.txt) deliberately
# EXCLUDES are reserved here and here only: Neferata, W'soran, Ushoran, Abhorash and the rest of
# Lahmia's immortal court.
# W'soran is encoded as the token Wsoran — the apostrophe is rendered through its loc key, the same
# way multi-word names are handled via the underscore convention.
# Lahmia has a real, still-reigning queen, so this culture DOES get noble last names and regal
