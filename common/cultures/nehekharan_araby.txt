# Old World cultures — Nehekhara and Araby. Schema mirrors common/cultures/norscan_humans.txt and
# common/cultures/chaos_dwarf.txt, the verified reference entries for this mod. Each culture
# carries:
#   color      — rgb{ R G B } with 0-255 integers. Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
# Multi-word names use vanilla's underscore convention (of_Khemri), displayed via the loc key —
#                the same convention as bretonnian's de_Lyonesse in common/cultures/brettonian_humans.txt.
# graphics/ethnicities — vanilla ships no Nehekharan or Arabyan portrait set; the north-african /
#                near-eastern vanilla pairing below is the closest real analogue and is used as a
#                STAND-IN pending custom art, which is out of scope for epic #3404.
# Every name string used below also needs a matching localization key unless vanilla already ships
# one — see localization/english/cultures_names_l_english.yml. Every culture additionally needs
# its six static modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Culture display names live in localization/english/cultures_nehekharan_araby_l_english.yml.
# arabyan (appended below) is the living Arabyans; nehekharan is the Tomb Kings.
# Board items #3409 (epic #3404), #8473 (epic #8462).

################ Nehekharan — the Tomb Kings; the living dead of the Great Land ################
# heritage_nehekharan sits in its OWN trait group (heritage_group_nehekharan), deliberately apart
# from heritage_group_undead, which holds the vampire/Mousillon Nagashite line: Nehekhara's dead
# are risen by the Mortuary Cult's own rites and make war on the necromancers who defiled them.
# Keeping the two undead traditions distinct is this culture's whole thesis, so the name lists
# deliberately exclude every name belonging to the Nagashite side (Nagash, Neferata, Arkhan,
# W'soran, Lahmia and their derivations — filed instead as lahmian_vampire in
# common/cultures/vampire.txt).
# Register: ancient-Egyptian-inflected, canon-first where it fits (Settra, Khalida, Nekaph,
# Khatep, Ramhotep, Lahmizzash, Apophas, Phar).
# Last names take the city-of-origin form. Victoria 3 has no separate "title" field, so
# "X of Khemri" is encoded as the last-name string of_Khemri and rendered through its loc key.
# Nehekhara has real, named, still-reigning rulers, so this culture gets both a noble last-name
# list and regal first-name lists.
