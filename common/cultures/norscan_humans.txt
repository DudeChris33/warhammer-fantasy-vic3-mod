# Old World cultures — Norscan humans. Schema confirmed against a vanilla Victoria 3 reference
# copy of common/cultures/00_cultures.txt (the north_german / south_german entries). Each culture carries:
#   color      — rgb{ R G B } with 0-255 integers (hsv{ h s v } is the other valid form). Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#                They are NOT wrapped in a traits = { } block — the parser rejects that outright.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
#   graphics/ethnicities — vanilla portrait ids (european, caucasian_blond), both confirmed present in
#                the vanilla common/culture_graphics/ and common/ethnicities/ databases. Custom art is
#                out of scope for epic #3404.
# Every name string used below also needs a matching localization key — see
# localization/english/cultures_names_l_english.yml. Every culture additionally needs its six static
# modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Culture files in this mod group by RACE/CULTURE-GROUP, not by the geography of the states a
# culture happens to occupy — see common/cultures/dwarven.txt for the convention's origin case.
# Board item #3407 (epic #3404).
