# Old World cultures — the greenskins (orcs, goblins and their Hobgobla Khanate kin). Schema
# mirrors common/cultures/norscan_humans.txt and common/cultures/chaos_dwarf.txt, the verified
# reference entries for this mod. Each culture carries:
#   color      — rgb{ R G B } with 0-255 integers. Cosmetic only.
#   religion   — a religion id from common/religions/00_religions.txt.
#   heritage   — a heritage discrimination-trait id from common/discrimination_traits/00_heritages.txt.
#   language   — a language discrimination-trait id from common/discrimination_traits/01_languages.txt.
#                heritage and language are SEPARATE top-level culture fields, each taking a single id.
#   traditions — required field; an empty block is valid and is what this mod uses for now.
#   obsessions — goods ids; empty until this mod authors common/goods/.
# graphics/ethnicities — vanilla ships NO greenskin portrait set. The values used below are
#                deliberate STAND-INS chosen only so the culture renders at all; they are a
#                placeholder pending custom greenskin art (out of scope for epic #3404) and carry
#                no lore claim whatsoever about what orcs, goblins or hobgoblins look like.
# FEMALE NAME LISTS: greenskins are canonically fungal and sexless — there are no female orcs,
#                goblins or hobgoblins in the setting. Victoria 3 nevertheless requires both pop
#                sexes to draw names, so female_common_first_names is populated from the SAME
#                register and word pool as the male list rather than inventing a separate "female
#                greenskin" naming tradition. This is a deliberate engine accommodation, not lore.
# Orc, goblin and hobgoblin share heritage_group_greenskin (#3408): greenskins are mutually
# tolerant AS A RACE. The running orc/goblin feud is carried entirely by the religion split — orcs
# put Gork (brutal cunning, strength-forward) first, goblins put Mork (cunning brutality) first —
# not by heritage. Hobgoblin is filed here with its greenskin kin rather than with the Chaos
# Dwarfs it serves in common/cultures/chaos_dwarf.txt: culture files in this mod group by
# RACE/CULTURE-GROUP, not by the geography of the states a culture happens to occupy or the
# masters it happens to serve — see common/cultures/dwarven.txt for the convention's origin case.
# Every name string used below also needs a matching localization key unless vanilla already ships
# one — see localization/english/cultures_names_l_english.yml. Every culture additionally needs
# its six static modifier definitions — see common/static_modifiers/culture_*_modifiers.txt.
# Culture display names live in localization/english/cultures_greenskin_l_english.yml.
# Board items #3408, #3409 (epic #3404).

# Urgok, Wurrzag, Gorfang, Grom, Morglum, Gnashrak, Ugezod, Borgut).
# Last names are EARNED BOASTFUL EPITHETS, not family names — orcs have no lineage, no
# ancestry and no inheritance, so there is no noble list and no regal list either: a Warboss
